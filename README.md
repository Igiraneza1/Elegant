# Elegant – E-commerce Frontend

Elegant is a modern e-commerce application built with Next.js 15, TypeScript, and Tailwind CSS. Designed with performance and scalability in mind, Elegant features reusable components for product displays, article sections, and a responsive, user-friendly footer. The project is fully optimized for production and seamlessly deployed on Vercel.

#  Features

 Next.js 15 App Router

Tailwind CSS styling

TypeScript for type safety

Responsive layout

SEO optimized

Vercel deployment-ready

#  Deployment

This project is ready for deployment on Vercel.

To deploy:

Push to GitHub

Connect the repo to Vercel

Set the root directory to / if using the App Router

Trigger a deployment
